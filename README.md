# PenguinEngine

Geplante 2D-Engine in C17 mit SDL3 und einem einfachen ECS. Dazu entsteht ein minimaler Editor mit Dateibaum, Tilemap-Werkzeugen, Zoom und Undo/Redo.

Die Engine soll langfristig Shooter im Stil von TwinBee, Top-down-Abenteuer und Metroidvanias unterstützen. Physik, JavaScript-Scripting und ein Dialogeditor folgen schrittweise.

**Aktueller Stand: Konzeptphase. Engine und Beispielprojekt sind noch nicht implementiert.**
